## About Chemistry Explorer

Chemistry Explorer is a browser-based education project designed to make core chemical concepts easier to explore through interactive modules and visual comparisons. It brings together periodic table navigation, element data, and trend charts so learners can move between reference-style information and graphical analysis without leaving the same interface.

Built with vanilla JavaScript and Chart.js, it is well suited to students, educators, and self-directed learners who want a lightweight web experience focused on chemistry topics. The module-based layout helps keep related data organized, making it easier to inspect individual properties such as electronegativity or atomic radius while also comparing how those values change across elements.

## Usage

Open the web app and choose a module to begin exploring chemistry data.

Typical workflow:
- Start with the periodic table to select an element
- Switch to a property chart such as ionization energy or atomic radius
- Compare trends across multiple elements
- Review electron configuration, oxidation states, and classification details for a selected element
- Use the visualizations to connect numeric values with periodic behavior

Because the project is web-based, the main interaction happens directly in the browser.
